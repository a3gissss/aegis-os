# Aegis OS

A personal productivity system built with plain HTML, CSS and JavaScript.

- **Tasks** with deadlines
- **Habits** with a 7-day tracker and streaks
- **Goals** broken into steps with progress bars
- **Study** timer (25/5 focus and break) with a session log
- **Notes** with autosave and search
- **Backup** export and import
- Installable as an app (PWA) and works offline

All data is stored in your own browser (localStorage). Nothing is sent to a server.

## Run locally

```bash
python -m http.server 5500 --bind 127.0.0.1
```

Then open http://localhost:5500.
